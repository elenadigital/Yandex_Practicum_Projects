# Рекомендация тарифов


## Задача проекта

Нужно построить модель для задачи классификации, которая выберет подходящий тариф оператора мобильной связи: «Смарт» или «Ультра». 
В качестве метрики качества будем использовать *accuracy*.

## Описание данных

В нашем распоряжении данные о поведении клиентов, которые уже перешли на тарифы «Смарт» или «Ультра». 

## План исследования

* Изучить датасет
* Разделить исходные данные на 3 части: обучающую, валидационную и тестовую выборки
* Определить целевой признак и создать отдельные датасеты с целевым и прочими признаками для предсказаний для каждой выборки
* Определить, к какому виду исследования относится наше исследование: Классификация или Регрессия
* Определить, какие модели обучения будем тестировать
* Тест моделей на обучающей и валидационной выборках
* Определение лучшей модели и гиперпараметров (с лучшим показателем accuracy)
* Проверить качество лучшей модели на тестовой выборке, достичь accuracy не меньше 0.75

## Решение

**Протестировали 3 модели Классификации:**

* Решающее дерево (Decision Tree)
* Случайный лес (Random Forest)
* Логистическая регрессия (Logistic Regression) 

**В ходе исследований получили результаты:**

* Точность (accuracy) модели Решающего дерева: 0.785, при max_depth равной 3.
* Точность (accuracy) модели Случайного леса: 0.764, при max_depth равной 5 и n_estimators равному 2.
* Точность (accuracy) модели Логистической регресии: 0.779

Лучший результат показала модель Решающего дерева: 0.785 (max_depth = 3).  

**Далее проверили качество этой модели на тестовой выборке.**
 
Мы получили accuracy равное 0.776, что означает, что наша модель показывает хорошие результаты на новых данных.
