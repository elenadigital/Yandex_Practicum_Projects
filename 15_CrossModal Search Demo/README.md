# Поиск по изображениям

## Задача проекта

Нужно разработать демонстрационную версию поиска изображений по запросу.

Для демонстрационной версии нужно обучить модель, которая получит векторное представление изображения, векторное представление текста, а на выходе выдаст число от 0 до 1 — покажет, насколько текст и картинка подходят друг другу.

## Описание данных

Датасет содержит экспертные и краудсорсинговые оценки соответствия текста и изображения.

В файле с экспертными мнениями для каждой пары изображение-текст имеются оценки от трёх специалистов. Для решения задачи нужно  агрегировать эти оценки — превратить в одну.

В файле с краудсорсинговыми оценками информация расположена в таком порядке:

1. Доля исполнителей, подтвердивших, что текст **соответствует** картинке.
2. Количество исполнителей, подтвердивших, что текст **соответствует** картинке.
3. Количество исполнителей, подтвердивших, что текст **не соответствует** картинке.

Модель должна возвращать на выходе вероятность соответствия изображения тексту, поэтому целевая переменная должна иметь значения от 0 до 1.

## План исследования

1. Загрузить библиотеки и данные 
2. Провести исследовательский анализ данных
3. Подготовьте данные к обучению модели:
    * Создать список слов, которые, могут попадать под юридические ограничения.
    * Исключить из обучающего датасета пары, которые, исходя из подготовленного списка слов, могут попадать под юридические ограничения.
    * Сделать векторизацию текстового описания
    * Сделать векторизацию изображений с использованием модели ResNet50 из библиотеки Keras / PyTorch.
    * Дать описание получившихся пар векторов с точки зрения их размерностей.
4. Создать модель, которая покажет близость двух векторов. Выбрать метрику, по которой будем сравнивать точность моделей. Обучить несколько моделей и подобрать гиперпараметры.
5. Тест лучшей модели и демонстрация ее работы
6. Общий вывод

## Решение

Обучили на тренировочной выборке 3 модели, в качестве метрики использовали RMSE:

* LinearRegression
* LinearRegression (Ridge)
* Нейронную сеть TensorFlow/Keras с несколькими слоями полносвязных нейронов
  
Модель Ridge показала лучший результат RMSE 0.35. Ее использовали при тестировании модели.
Напиcали функцию, принимающую на вход текстовое описание и возвращающую 5 похожих картинок.
Функция принимает на вход текст и находит изображения, отбрасывая изображения лиц младше 16. Но, к сожалению, предсказывает картинки некорректно.

Рекомендации для улучшения качества модели:

* Проверить этапы векторизации текстов и изображений
* Протестировать использованные модели с другими гиперпараметрами
* Протестировать другие модели/нейронные сети с тщательным подбором гиперпараметров.
