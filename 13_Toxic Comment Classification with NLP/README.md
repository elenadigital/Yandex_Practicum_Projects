# Классификация токсичных комментариев

## Задача проекта

Интернет-магазину нужен инструмент, который будет искать токсичные комментарии и отправлять их на модерацию. 
Нужно обучить модель классифицировать комментарии на позитивные и негативные.
В качестве метрики использовать *F1* (значение должно быть не меньше 0.75). 

## Описание данных

**Инструкция по выполнению проекта**

В нашем распоряжении набор данных с разметкой о токсичности правок.
Столбец **text** в датасете содержит текст комментария, а **toxic** — целевой признак.

## План исследования

1. Загрузка и ознакомление с данными
2. Предварительная обработка данных
3. Разведочный анализ данных
4. Векторизация текстовых данных с использованием TF-IDF
5. Выбор и обучение моделей
6. Итоговая оценка качества предсказания лучшей модели
7. Построение Матрицы ошибок и графика тoчнocти-пoлнoты (precision recall curve)
8. Вывод

## Решение

На этапе обучения тестировали модели:

* LogisticRegression
* RandomForestClassifier
* CatBoostClassifier

Для оценки качества моделей была выбрана метрика F1-мера.

В результате обучения лучший результат показала модель LogisticRegression c f1-мерой 0.77. Эту модель взяли для обучения и предсказания на тестовой выборке.

В результате обучения лучшей модели LogisticRegression и предсказания на тестовой выборке получили результат:

* F1-мера 0.78
* Precision 0.85
* Recall 0.72

Таким образом, построили модель со значением метрики качества F1 не меньше 0.75.
